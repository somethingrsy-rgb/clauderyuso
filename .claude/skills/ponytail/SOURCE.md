# Source

These skills (ponytail, ponytail-review, ponytail-audit, ponytail-help,
ponytail-debt, ponytail-gain) are copied unchanged from
https://github.com/DietrichGebert/ponytail at commit c982cd4 (MIT License, see
LICENSE next to this file). Only the SKILL.md instruction files were copied;
the repository's hooks/ scripts were deliberately left out.

To turn the skill off for this repository, delete the ponytail* folders in
.claude/skills/.
